# Pilot Checklist

- [ ] Public HTTPS webhook registered and `/ready` reports ready.
- [ ] Test channel and discussion group connected.
- [ ] Bootstrap and delegated administrators verified.
- [ ] One-time and weekly reminders delivered at the expected local time.
- [ ] Short sermon processed into transcript and draft posts.
- [ ] Draft reviewed, approved, and delivered on schedule.
- [ ] Bible assistant ordinary question reviewed by a church leader.
- [ ] Safety escalation examples produce no improvised professional advice.
- [ ] Database backup created and restored into a disposable database.
- [ ] Logs and uptime alerts observed for at least 48 hours.
- [ ] Church leader approves moving from test group to the real group.
